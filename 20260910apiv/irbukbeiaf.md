# 用药指南|丽申宝促排药注意，能自然怀孕吗？

> 更新时间：2026-09-10 (UTC+8)

随着试管婴儿技术的逐渐普及，越来越多无法生育的家庭通过该项技术，获得了自己的孩子。而做试管婴儿的女性大多会经历促排卵这一过程，在这段时间中，女性身体和心里都有一定程度的压力。并且很多促排药还需要自己上手，这就需要女性知道注射促排药的方法，那么今天就一起来看看丽申宝是怎么注射的吧！

## 注射丽申宝具体步骤

丽申宝是国产的促排药，是通过肌肉注射的一种针剂，一般都是在臀部注射。因为促排期间会经常打针注射，所以很多患者都是自行在家注射丽申宝。

需要注意的是，丽申宝注射剂量每天应该在75~150单位之间。且丽申宝一般多用于不排卵（包括多囊卵巢综合征）且对枸橼酸克罗米芬治疗无效者，还有辅助生殖技术超促排卵者，具体注射步骤如下。

- 1. 洗手，尽可能保持手及所有物品的清洁；
- 2. 取坐位或卧位，用爱尔碘皮肤消毒液或75%酒精进行皮肤消毒，待干；
- 3. 排尽抽取药物之注射器内空气；
- 4. 用左手拇指和食指分开皮肤，右手持针如握笔姿势，以中指固定针栓。针头和注射部位程垂直，快速刺入肌肉内，中心一般深部肌肉注射，因激素药刺激性大，以减轻疼痛感；
- 5. 松开左手，抽动活塞，如无回血，固定针头，注入药物。注射毕，以干棉签按压进针处，同时快速拔针。

丽申宝注射后很可能出现注射部位不适，或发热、关节疼痛，这都属于常见的丽申宝不良反应，基本不需要特殊处理。但如果出现了腹痛、腹胀、卵巢增大、呼吸困难等症状，这就可能引发了卵巢过度刺激综合症需及时就医。

## 丽申宝促排的相关注意事项

丽申宝虽能在试管促排中起到很好的作用，并且由于是国产药，一支丽申宝费用也不高，但丽申宝依旧要谨慎使用，不能过于盲目，应提前了解其注意事项来减少其副作用发生的概率。

1、不宜过量

用药者在使用丽申宝过程中，需明确丽申宝怎么打，并严格控制丽申宝的注射剂量，过量使用丽申宝容易造成卵巢过度刺激症，最好在医生的指导下进行注射。

2、忌吃高糖分的食物

注射丽申宝期间使用高糖分的食物后，很容易导致出生后的胎儿体重过高，或增加胎儿先天性畸形的概率，因此在使用丽申宝过程中不宜食用高糖分的食物。

3、出现副作用须及时就医

丽申宝的副作用并不少，如果用药者在注射期间出现不适，应立即就医，通过适当的医疗措施来控制出现的副作用，这样才能避免更严重的情况发生。
